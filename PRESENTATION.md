## 🎬 The Problem

We all face these daily challenges:
- 🍽️ "What should I cook with these random ingredients?"
- 📚 "How do I organize all these deadlines?"
- ⏰ "What's the best way to structure my day?"
- 📧 "This email is too long - what are the key points?"
- 💡 "I need a quick productivity tip"

**Traditional solutions**: Search Google, scroll through articles, get overwhelmed with information.

**Our solution**: Ask emini - get instant, personalized, contextual help!

---

## 🚀 The Solution

**emini** combines:
1. **Nostalgic digital pet** (like Tamagotchi) 
2. **AI assistant** (powered by Google Gemini)
3. **Context awareness** (time of day, user needs)

### Key Innovation
Unlike generic chatbots, emini:
- ✅ Provides **bite-sized, actionable suggestions**
- ✅ Uses **context** (time, clipboard, pet status)
- ✅ Has **personality** (your pet companion)
- ✅ Works **entirely in your browser** (privacy-first)

## 🛠️ Technical Stack

### Frontend
- **HTML5** - Structure
- **CSS3** - Styling with gradients and animations
- **Vanilla JavaScript** - No frameworks, pure performance

### AI Integration
- **Google Gemini Pro API**
  - Temperature: 0.7 (balanced creativity)
  - Max tokens: 200 (concise responses)
  - Context-aware prompting

### Architecture
- **Object-Oriented Design**
  - `Pet` class: Pet behavior and stats
  - `AIHelper` class: Gemini API integration
- **Event-Driven**: Responsive UI updates
- **Local-First**: API keys stored in localStorage

## 🔒 Privacy & Security

### Privacy-First Design
- ✅ **No server**: Runs entirely in browser
- ✅ **No tracking**: Zero analytics or cookies
- ✅ **Local storage**: API keys never leave your device
- ✅ **Minimal data**: Only sends your questions to Gemini API

### Data Flow
```
User → Browser → Google Gemini API → Response → Browser → User
```
**No intermediary servers. No data storage.**
