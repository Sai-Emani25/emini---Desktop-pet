# 🚀 Quick Start Guide - emini AI Co-Pilot

## Step 1: Get Your Free Google Gemini API Key

1. **Visit**: https://makersuite.google.com/app/apikey
2. **Sign in** with your Google account
3. Click **"Create API Key"** button
4. **Copy** the API key (it looks like: `AIzaSy...`)
5. Keep it secure - don't share it publicly!

## Step 2: Open the App

1. Double-click `index.html` in the project folder
   - OR use Live Server in VS Code
   - The app will open in your browser

## Step 3: Configure AI Helper

You'll see the AI Co-Pilot section at the bottom:

1. Find the input field that says "Enter Gemini API key..."
2. **Paste** your API key
3. Click **"Save"** button
4. Wait a few seconds...
5. ✅ Status should change from "Offline" to **"Online"** 🟢

## Step 4: Try It Out!

#### 1️⃣ Smart Tip

### Common Questions:

**Q: Is the API key safe?**
A: Yes! It's stored only in your browser's localStorage. It's not sent anywhere except to Google's Gemini API.

**Q: Is it free?**
A: Yes! Google Gemini has a generous free tier for personal use.

**Q: Can I use it offline?**
A: No, you need internet connection to communicate with the Gemini API.

**Q: What if I get an error?**
A: Check that:
- Your API key is correct
- You have internet connection
- You haven't exceeded the free tier quota

## 🆘 Need Help?

### Troubleshooting

**AI shows "Offline"**
→ Re-enter your API key and click Save

**"Could not access clipboard"**
→ Allow clipboard access when browser asks

**Suggestions are too generic**
→ Be more specific in your questions

**API quota exceeded**
→ Wait 24 hours or upgrade to paid tier
